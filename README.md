# The Excel Revue

A curated collection of funny, strange, and painfully relatable Excel posts, screenshots, memes, and spreadsheet observations.

This project is inspired by Debra Dalgleish's original Excel Theater roundups, which collected some of the best Excel humor from the community. Formula Follies is an independent continuation of that general idea with its own name, format, and editorial direction.

## What belongs here?

- Funny Excel and spreadsheet posts
- Excel-specific memes
- Painfully familiar workplace spreadsheet situations
- Clever formulas and unexpected spreadsheet behavior
- Observations about analysts, finance teams, reporting, and data work
- Posts that capture the strange culture surrounding Excel
